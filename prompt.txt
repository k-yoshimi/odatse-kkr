================================================================================
KKRパラメータ設定機能と再計算機能の統合プロンプト
================================================================================

以下の機能をこのプロジェクトに統合してください。

--------------------------------------------------------------------------------
1. 必要なimportの追加
--------------------------------------------------------------------------------

odatse_kkrから以下の関数/クラスをimportしてください：

```python
from odatse_kkr import (
    # 既存のimport...
    # 以下を追加
    ConvergenceError,
    RetryConfig,
    apply_kkr_parameters_from_config,
    check_convergence,
    run_with_retry,
)
```

--------------------------------------------------------------------------------
2. KKRパラメータ設定機能
--------------------------------------------------------------------------------

`load_input_file()`で読み込んだ後に、`apply_kkr_parameters_from_config()`を
呼び出してTOMLの[kkr]セクションの設定を適用してください：

```python
# Load base input data and apply KKR parameters from config
self.base_input_data = load_input_file(self.template_input)
self.base_input_data = apply_kkr_parameters_from_config(
    self.base_input_data, config
)
```

--------------------------------------------------------------------------------
3. 再計算機能（RetryConfig）
--------------------------------------------------------------------------------

### 3.1 初期化時にRetryConfigを読み込み

`__init__`メソッドで以下を追加：

```python
# Retry configuration for convergence failures
self.retry_config = RetryConfig.from_config(config)
if self.retry_config:
    logger.info(
        f"Retry on convergence failure enabled: "
        f"ewidth_list={self.retry_config.ewidth_list}"
    )
```

### 3.2 AkaiKKR実行部分の変更

`run_command_template()`を`run_with_retry()`に置き換え：

```python
def on_retry(attempt: int, new_ewidth: float) -> None:
    logger.info(f"Retry {attempt}: ewidth={new_ewidth}, record=2nd")

try:
    attempts = run_with_retry(
        self.command_template,
        work_dir=calc_dir,
        input_path=input_path,
        output_path=output_path,
        env=env,
        timeout=self.command_timeout,
        retry_config=self.retry_config,
        on_retry=on_retry,
    )
    if attempts > 1:
        logger.info(f"Converged after {attempts} attempt(s)")
except ConvergenceError as e:
    logger.error(f"Convergence failed: {e}")
    raise
```

--------------------------------------------------------------------------------
4. TOML設定例
--------------------------------------------------------------------------------

```toml
# KKRパラメータ設定（任意のパラメータのみ指定可能）
[kkr.output]
bzqlty = 2

[kkr.calculation]
edelt = 0.001
ewidth = 2.0

[kkr.lattice]
a = 7.5

# 再計算設定（収束失敗時に有効）
[kkr.retry]
ewidth_list = [2.0, 2.5, 3.0, 3.5]
change_record_on_retry = true
```

--------------------------------------------------------------------------------
5. 動作仕様
--------------------------------------------------------------------------------

1. **KKRパラメータ設定**: 
   TOMLの`[kkr]`セクションで指定されたパラメータがtemplate.inの値を上書き

2. **再計算**: 
   出力に"no convergence"が含まれる場合、自動的に：
   - `ewidth`を`ewidth_list`の次の値に変更
   - `record`を`"init"`から`"2nd"`に変更
   - 再計算を実行

3. すべてのewidth値で収束しない場合は`ConvergenceError`を発生

--------------------------------------------------------------------------------
6. 利用可能なKKRパラメータ
--------------------------------------------------------------------------------

[kkr.go]
- command: goコマンド（デフォルト: "go"）
- pot_file: ポテンシャルファイル名（デフォルト: "pot.dat"）

[kkr.lattice]
- brvtyp: ブラベー格子タイプ
- a: 格子定数a
- c_a: c/a比
- b_a: b/a比
- alpha, beta, gamma: 格子角度

[kkr.calculation]
- edelt: エネルギーメッシュ幅
- ewidth: エネルギー窓幅
- reltyp: 相対論タイプ（sra等）
- sdftyp: SDFタイプ（mjw等）
- magtyp: 磁性タイプ（mag等）
- record: レコードタイプ（init, 2nd等）

[kkr.output]
- outtyp: 出力タイプ
- bzqlty: BZ品質
- maxitr: 最大反復回数
- pmix: ミキシングパラメータ

[kkr.retry]
- ewidth_list: 試行するewidth値のリスト
- max_retries: 最大リトライ回数（デフォルト: len(ewidth_list) - 1）
- change_record_on_retry: リトライ時にrecordを変更するか（デフォルト: true）
